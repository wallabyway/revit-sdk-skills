Revit SDK Skills

Public documentation knowledge base for the Autodesk Revit API

Public GitHub Pages URL
wallabyway.github.io/revit-sdk-skills

What is this?

This site hosts a searchable, agent-readable reference of the Revit API. The documentation is split by Revit release year and organized by technical domain (application lifecycle, geometry, MEP, structural, events, exceptions, etc.).

The entry point for agents is SKILL.md. It tells an agent which topic files to read for a given Revit API question.

How to install / use this skill

Point your agent at the public URL and ask it to read SKILL.md first. The agent can then retrieve the relevant sub-markdown files on demand.

Claude Code

  • Add this project instruction to your repo's CLAUDE.md or Claude Code project settings:
When answering questions about the Autodesk Revit API, first read
https://wallabyway.github.io/revit-sdk-skills/SKILL.md, then retrieve the topic
files it recommends for the specific namespace or class being asked about.
  • Alternatively, paste the URL https://wallabyway.github.io/revit-sdk-skills/SKILL.md into the chat and ask Claude to use it as the source of truth.

OpenAI Codex

  • In Codex CLI, add the URL to your project instructions or .codex/instructions.md:
For Revit API questions, fetch https://wallabyway.github.io/revit-sdk-skills/SKILL.md
and follow its retrieval strategy. Read only the topic files relevant to
the user's specific namespace, class, or workflow.
  • In ChatGPT with Codex, share the URL and ask Codex to browse it, then dive into the linked topic files.

Kimi Code

  • Create a project skill or custom instruction that loads the steering file:
Load https://wallabyway.github.io/revit-sdk-skills/SKILL.md as the Revit SDK skill.
When the user asks about Revit API types, methods, or workflows, read the
per-year INDEX.md to locate the exact type, then retrieve the matching topic file(s).
  • Or clone the repo and reference the local docs/SKILL.md directly from Kimi Code's skill configuration.
Tip: Always point the agent at .../SKILL.md, not just the root page. SKILL.md contains the retrieval strategy and categorized index that lets the agent decide which sub-files are worth reading.
